Why This Server Exists

Purpose: Self-hosted Minecraft Java server for personal/family use, running on existing Proxmox infrastructure without cloud subscription costs.

Why Self-Host?

ReasonExplanation
💰 CostNo monthly Realms subscription ($4-8/month). Uses existing Proxmox hardware.
🔒 ControlFull admin access, custom plugins, mod support, world backups on your schedule.
👥 PrivacyYour world data stays on your hardware. No third-party servers.
⚡ PerformanceDedicated resources (4GB RAM, 2 cores) vs shared Realms hosting.
🎓 LearningPractice Linux admin, systemd, networking, automation, containerization.

Why Proxmox LXC?

ReasonExplanation
🖥️ Existing LabProxmox already running for other VMs. Adding a container is free.
📦 IsolationContainer separates Minecraft from host system. Easy backup/restore.
🔄 SnapshotsProxmox can snapshot entire container before risky updates.
⚡ LightweightLXC shares host kernel. Lower overhead than full VM.
🌐 NetworkBridge networking gives container its own IP on LAN.

Lessons Learned

Paper 1.21.4 is no longer available. The API returns no builds. Always use the latest version or omit the version argument.
Debian 12 minimal images lack basic tools. git, curl, wget, jq must be installed manually with apt-get.
Container 102 uses Debian, not Ubuntu. The proxmox-lxc-setup.sh template was not used; container was created differently.
Password SSH is disabled. Container only accepts keys. Use pct exec 102 -- bash or Proxmox console.
First startup takes ~50 seconds. Paper remaps obfuscated code on first run. This is normal behavior.
Auto-start requires two levels: systemctl enable minecraft (inside container) AND pct set 102 --onboot 1 (on Proxmox host).
JVM heap auto-detects from container RAM. Formula: (total_MB - 1024) / 1024 with 1GB minimum.
